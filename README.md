#  SuperMart-TSQL-Capstone
A collection of SQL queries and results, Excel worksheets and other data analysis tools. Combined for the 2026 Capstone Assignment.

Given the business scenario of a popular business SuperMart opening a new branch in Johannesburg and needing a Database Developer for their Data Cluster. A small database must be built to generate reports to help the sales department. The tasks given are the activities of the project, using T-SQL.
